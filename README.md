# ANI HOST — Minecraft Server Hosting

A futuristic starter dashboard for a Minecraft hosting platform inspired by the convenience of Aternos.

## Current prototype
- Responsive hosting landing page and control-panel preview
- Server software selector: Vanilla, Paper, Purpur, Fabric, Forge
- Java and Bedrock server cards
- Interactive demo controls and console preview

## Important
This repository currently contains a **frontend prototype**. Start/stop buttons and console are demo interactions; they do not launch a real Minecraft server yet.

A real hosting service also needs backend APIs, user authentication, persistent server storage, and Linux machines/containers to run Minecraft. Vercel or GitHub Pages can host the website, but not persistent game servers by themselves.

## Run locally
Open `index.html` in a browser, or deploy the repository as a static site.
